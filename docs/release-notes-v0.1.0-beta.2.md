# Spoiler-Free Quest Hints v0.1.0-beta.2

## English

This beta fixes several reviewed research rules that had not yet been promoted into the runtime UI rule set.

### Added to the in-game UI

- **Gimme Danger** — quest-level `Relationship` impact, plus a `Worth noting` reminder before the Takemura reconnaissance choice.
- **Ghost Town** — quest-level `Relationship` impact, plus two `Worth noting` reminders around Panam relationship-building moments.
- **Blistering Love** — quest-level `Follow-up quest / Ending condition` impact.
- **Dream On** — quest-level `Relationship` impact, plus a `Worth noting` reminder at the final Jefferson conversation.

The release archive contains only the runtime redscript files required by the mod.

Download `SpoilerFreeQuestHints-v0.1.0-beta.2.zip` and install it through Vortex or extract it into the Cyberpunk 2077 game root.

## 中文

这个 Beta 修复了几条“研究库已经筛选完成，但尚未晋升到游戏 UI 正式规则”的遗漏。

### 新增到游戏 UI 的规则

- **危险游戏 / Gimme Danger**：任务级 `人物关系`，并在竹村侦察选择前显示 `值得留意`。
- **死城 / Ghost Town**：任务级 `人物关系`，并在两个帕南关系相关阶段显示 `值得留意`。
- **往日之影 / Blistering Love**：任务级 `后续任务 / 结局条件`。
- **Dream On**：任务级 `人物关系`，并在最后与 Jefferson 交谈时显示 `值得留意`。

发布包只包含模组运行所需的 redscript 文件。

请下载 `SpoilerFreeQuestHints-v0.1.0-beta.2.zip`，通过 Vortex 安装，或直接解压到《赛博朋克 2077》游戏根目录。
